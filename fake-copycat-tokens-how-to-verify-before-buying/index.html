Fake copycat tokens: How to verify before buying

How to spot fake copycat tokens with the same name: match the contract to the issuer’s official address, then compare its age, holders and liquidity.

The Blocktape Editors Nov 21, 2026 · 14:07 UTC2 min read 6c12a0

Before a first swap, spot a fake token using a real token’s name by matching its contract address character by character against the issuer’s official source, then checking its age, holders and liquidity against the original.

An ERC-20 token’s name and symbol are not unique: anyone can deploy a contract using the same ones. The contract address identifies which token you are actually considering, so start with an address published on the issuer’s own site or in its official docs.

Use this checklist before buying:

  • Official address match. Find the contract address on the issuer’s site or official docs and compare every character with the address in the swap interface. A matching name or symbol is not a substitute for an exact address match.
  • Contract age. Open the address in Etherscan and compare its deployment date with the original contract. A much newer deployment using an established token’s name is a reason to stop and verify the address again.
  • Holder count. Compare the number of holders shown for the candidate and the original. A copy can be young and thinly held even when a pool shows a price; the price alone doesn’t establish that the token is genuine.
  • Liquidity location. Check where liquidity sits for each contract, and compare the pools rather than relying on a displayed price. A pool for the copy can exist without being the market for the original token.
  • Import warning in the interface. cowswap, a decentralized exchange interface, shows a warning when you import a token that is not on its active token lists. For a well-known name, treat that warning as a signal that the address is not the listed one and recheck it against the issuer’s source. Its cowswap limit orders feature is a concrete example of a trade instruction tied to a specific token, making contract identity relevant when setting the order.
  • Unrequested tokens arriving in the wallet. Don’t treat a token that appears without you seeking it out as proof that it belongs to a known project. Before any swap, look up its contract independently and run the other checks.

Compare the candidate directly with the original on Etherscan: deployment date, holder count and liquidity location together can expose a young, thinly held copy that a pool price makes look active. None of those checks replaces the issuer’s address; use them to catch mismatches before buying.

MetaMask custom networks disappear after a clean delete

To remove a network from MetaMask, switch away from it, delete the custom entry from its three-dot menu and confirm it disappears from your list on desktop or mobile.

The Blocktape Editors Nov 18, 2026 · 07:45 UTC2 min read ea5b09

To remove a custom network from MetaMask, switch to another network, open the network menu, use the custom entry’s three-dot menu, choose Delete, and confirm. The network should then disappear from your list.

A custom network is a wallet entry, not an on-chain object, so deleting it removes the entry from MetaMask without changing the blockchain. Chainlist is an EVM network directory that helps you connect a wallet to a network using details such as its Chain ID and RPC endpoint.

Before you start, have MetaMask unlocked and the custom network in your list. The active network cannot be deleted, so switch to a different one first; otherwise, its menu will not show Delete.

  1. Switch to another network in MetaMask. The new network becomes active, leaving the custom network available to manage.
  2. Open the network menu. In the extension, select the network control at the top of MetaMask; in the mobile app, tap the network name to open the network selector.
  3. Find the custom network and open its three-dot menu. The menu belongs to that network entry, so make sure you have selected the one you want to remove.
  4. Select Delete. Only custom entries can be removed; built-in networks such as Ethereum Mainnet have no Delete option. If Delete is missing, first make sure you have switched away from the network, then check that the entry is custom.
  5. Confirm the deletion. The custom network disappears from the MetaMask network list, which confirms the task is complete.

Removing the entry does not erase the network itself or affect activity recorded on it. MetaMask stores the network entry in your wallet, while the network’s Chain ID identifies the chain independently of that saved entry.

To use the network again later, add it back through Chainlist. The restored entry uses the same Chain ID, letting you reconnect MetaMask to that network.

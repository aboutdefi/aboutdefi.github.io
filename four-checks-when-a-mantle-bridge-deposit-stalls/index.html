Four checks when a Mantle bridge deposit stalls

A stalled Mantle deposit is usually diagnosed by checking the Ethereum transaction, token approval, destination address and Mantle balance before submitting again.

The Blocktape Editors Oct 16, 2026 · 14:11 UTC2 min read 72a9af

A Mantle deposit moves assets from Ethereum to Mantle after the source transaction is accepted and the cross-chain message is processed. If the balance has not appeared, check the transfer’s state before sending another deposit.

Did the Ethereum transaction succeed?

Find the transaction hash in your wallet and open it in an Ethereum block explorer. A pending transaction has not been confirmed; a failed one did not complete the deposit, while a successful one shows the source-side transaction was recorded.

The mantle bridge moves assets through steps on both networks, so a confirmed Ethereum transaction does not by itself prove the Mantle transfer is complete. The fuller explanation covers how those steps fit together.

Did the token approval and deposit both happen?

An ERC-20 token deposit may require a separate approval transaction before the deposit transaction. An approval grants the bridge contract permission to use tokens; it does not move them, so check your wallet history for both transactions.

Use these four checks to locate the break in the process:

  • Confirm that the Ethereum deposit transaction succeeded.
  • For an ERC-20, confirm that any required approval succeeded before the deposit.
  • Check the deposit details for the intended Mantle destination address.
  • Search the Mantle explorer for activity at that address and the expected token.

Why can the deposit be complete but the balance look missing?

A wallet can show different assets depending on its selected network and token list. Switch to Mantle and check the receiving address; if the explorer records a token transfer there but the wallet balance is absent, the issue may be token display rather than the bridge transfer.

Compare the asset and amount shown in the bridge history with the Mantle explorer record. If the Ethereum transaction succeeded but no corresponding Mantle activity appears, use the bridge’s history or support route and provide the source transaction hash, destination address and token details.

Do not submit the same deposit again while the first transfer is still processing. Once the explorers and bridge history identify its state, retry only if the original source transaction failed or no deposit was sent.

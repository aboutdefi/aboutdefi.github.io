How Can a Same-Nonce Replacement Speed Up Ethereum?

To speed up a pending Ethereum transaction, use the same account and nonce with higher fee settings; review the replacement, sign it, then track confirmation.

The Blocktape Editors Nov 23, 2026 · 03:09 UTC2 min read f8fd54

After a transfer sits pending, you can try to speed it up by opening it in the wallet that sent it, choosing Speed up, reviewing the higher fees and same nonce, and signing. Check the wallet or a block explorer afterward to see whether the replacement was confirmed.

A pending transaction can hold up later transactions from the same account because Ethereum processes them in nonce order. A nonce is the account’s transaction sequence number, and a confirmed transaction consumes its nonce. For a Matcha swap, how Ethereum nonces set a Matcha swap queue explains why later transactions may have to wait.

A replacement competes for the same nonce

Suppose nonce 12 is pending. A speed-up submits another transaction from the same account with nonce 12; raising its fee settings gives validators a stronger incentive to include it.

With EIP-1559, the transaction specifies maxFeePerGas and maxPriorityFeePerGas. A wallet’s Speed up control usually raises these values, but its acceptance of the replacement depends on the wallet and node policy. Review the proposed fees before signing.

This is a competing transaction, not an edit to the pending one. Whichever transaction with nonce 12 is included first consumes that nonce, so the original can no longer be included afterward. Inspect the replacement’s destination and action before signing; for a Matcha swap, make sure the swap is still what you intend to submit.

Use the wallet’s Speed up control, then check status

To try the replacement, open the wallet that sent the pending transaction and make sure it is set to the same account and Ethereum network. Open the pending transaction and select Speed up.

Review the replacement’s nonce and higher fee settings, then check its destination and action. For a Matcha swap, confirm that the displayed swap details still match your intent. Sign the transaction, then check its status in the wallet or an Ethereum block explorer.

Keep the pending transaction open while reviewing the replacement so you can compare the action and destination before signing. That quick check helps avoid confirming a competing transaction with the wrong details.

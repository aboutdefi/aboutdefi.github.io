XMR swap confirmations depend on the service’s release rules

For an XMR swap, wait for the service’s stated confirmation threshold; Monero averages two-minute blocks, but settlement rules decide when the payout is released.

The Blocktape Editors Sep 30, 20262 min read cce0d4

For an XMR swap, wait until the service marks the deposit as confirmed and the order as complete; there is no single confirmation count that applies to every swap. Monero’s technical specification sets an average two-minute block interval, but the service’s settlement rules determine when it releases the other asset.

A swap can involve separate blockchains, each with its own confirmation count. If the payout is USDT, for example, the network chosen for that payout affects how its arrival is tracked; this guide to choosing a USDT network for an XMR bridge payout explains that choice in more detail.

What does one XMR confirmation mean?

One confirmation means the transaction has been included in a Monero block. Monero’s wallet RPC documentation defines the count by the blocks mined since the block containing the transaction, so the displayed number may rise as new blocks arrive.

The two-minute block interval is an average, not a timer. A transaction can wait in the pool before inclusion, and blocks do not arrive on a fixed schedule; multiplying a confirmation count by two gives only a rough wait estimate.

Also, confirmation and spendability are different. Monero imposes a 10-block delay before a received output can be spent, which averages about 20 minutes after inclusion. That wallet rule does not, by itself, say when a swap service must release a payout.

How many confirmations should I wait for?

Use the confirmation threshold shown in the swap order or specified by the service. A brokered swap may wait for a set number of confirmations on the coin you send before releasing its payout; another service or protocol may use different conditions.

Check which chain the count refers to. “Six confirmations” might refer to the deposit coin’s blockchain, while the XMR payout has its own transaction and confirmation count. For a swap that crosses two networks, completing the deposit stage does not automatically mean the payout has arrived.

  • Before sending: read the order’s minimum amount, deposit deadline and confirmation requirement.
  • After sending: use the transaction ID and order status to see whether the deposit is still pending, confirmed or being processed.
  • For the payout: check its transaction ID in your synced Monero wallet and wait for the wallet to show the incoming transfer.

When is an XMR swap actually complete?

A swap is complete when the service reports completion and the expected payout appears in the receiving wallet, subject to any lock that prevents you from spending it. Treat a deposit marked “confirmed” as progress through the order, not proof that the XMR payout is already spendable.

If the displayed count exceeds the service’s stated threshold but the order remains pending, compare the transaction ID, amount and deposit address with the order details, then contact the service through its listed support channel. Do not send a second payment to resolve a delay unless the service confirms the first deposit failed and gives instructions for the same order.

For a large swap, allow more time than the minimum if the service permits it, and avoid relying on an unconfirmed deposit as settled. The practical rule is to follow the order’s network-specific threshold, then verify the payout in your wallet; the service’s status and the receiving chain’s confirmations show when the swap has moved through settlement.

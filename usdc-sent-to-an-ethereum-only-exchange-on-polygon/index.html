USDC sent to an Ethereum-only exchange on Polygon

Sent USDC on Polygon to an Ethereum-only exchange? Often it can be recovered, but only the exchange can retrieve it. Check the transaction and request recovery.

The Blocktape Editors Nov 27, 2026 · 14:23 UTC2 min read 45e43a

Sent USDC on Polygon to an Ethereum-only exchange? Often yes, but only the exchange can recover it.

What happens to USDC sent to an Ethereum-only exchange?

The USDC stays at the deposit address on Polygon PoS until someone moves it. The exchange watches Ethereum, so it will not see or credit a Polygon transfer, even when the address looks identical on both networks.

Ethereum and Polygon PoS use the same address format. If the exchange controls the private key for an Ethereum address, it also controls that address on Polygon. Recovery still depends on the exchange choosing and being able to retrieve the tokens.

The Polygon bridge moves supported assets between Polygon PoS and Ethereum, changing which chain holds them. It does not make an Ethereum-only exchange monitor a Polygon deposit.

Polygon PoS has native USDC issued by Circle and bridged USDC.e; they are separate tokens with separate contracts. Circle’s contract-address information distinguishes native USDC from USDC.e, and the token contract shown for your transfer identifies which one you sent.

How can I check the deposit and request recovery?

Polygonscan can confirm whether the transfer succeeded, which token contract received it, and the address that holds the USDC. Polygon PoS has chain ID 137; the deposit address may match the one shown by the exchange on Ethereum.

Take a case where you sent 50 USDC to an Ethereum-only exchange address. Polygonscan shows the transfer delivered, but the exchange account shows no deposit: the tokens are at that address on Polygon, not credited to your exchange balance.

Check the deposit address on Etherscan for contract code. When Etherscan shows code, the address is an exchange forwarder deployed on Ethereum, and that code is not automatically present at the same address on Polygon. The exchange must redeploy the forwarder on Polygon before it can recover tokens sent there; this can make recovery harder or impossible.

Send exchange support the Polygon transaction hash, token contract, amount and deposit address. Include that the transfer was on Polygon PoS, and ask whether they can retrieve that token from the address. The exchange’s response will determine whether the USDC can be returned or credited.

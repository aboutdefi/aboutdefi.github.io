How to read a TronLink swap popup for beginners: sign or reject

Read a TronLink confirmation before signing a SunSwap swap by matching the contract address, function name, call value and fee limit to your intended action; sign only if all four match.

Your signature authorizes the call shown in the popup, regardless of the swap summary on the website. The popup describes the transaction you submit.

What should you have ready for a TronLink swap confirmation?

For a TronLink confirmation, have the input token’s contract address and the router address for your swap version. For V2, the router is listed in SunSwap’s official interface documentation. Note your intended input token and amount. An approve call targets the token contract; the swap call targets the router.

At sunswap.cc, you can set up a TRC-20 token swap through liquidity pools on TRON. Keep that trade visible beside TronLink.

How do you check a TronLink approve or swap call?

Read a TronLink approve or swap call in order, deciding whether each field fits the proposed trade.

  1. Read the contract address. A swap popup should show the documented router. An approve popup should show the input token’s contract, with the router named as spender in the approval details. An unexpected address means the call differs from the one you prepared.
  2. Read the function name. Approve permits the named spender to use tokens up to the stated allowance. A swap function requests the exchange. If you expected approval but see a swap function, reject. Read any displayed allowance as the token amount authorized.
  3. Read the call value. It is TRX sent with this contract call. On a TRX-input swap, it should equal your TRX input; on a token-input swap or approve call, expect zero. Zero can still accompany a TRC-20 token swap.
  4. Read the fee limit. It caps the caller’s Energy budget and the TRX burned for Energy; it is not the charge. Available Energy covers usage first, with TRX burned for a shortfall. Actual burn varies with Energy used and available resources. A low limit can make execution fail, while a higher one is not automatically spent in full. TRON’s fee limit documentation explains the cap.
  5. Sign or reject, then verify. Sign only when all four fields match; otherwise reject. After confirmation, open the transaction on TRONSCAN. Its contract and function should match the popup. Under resource consumption, read actual Energy use and TRX burn; TRONSCAN’s transaction detail reference identifies these fields. The task is done when the recorded contract and function match.

Approval and swap calls have separate transaction records, so compare each with its own popup. For a SunSwap exchange through TRON liquidity pools, continue at sunswap.cc when you are ready to swap.

  • Match the contract and function to the intended action.
  • Call value is TRX sent; fee limit caps Energy spending.
  • TRONSCAN shows the recorded call and actual resource consumption.

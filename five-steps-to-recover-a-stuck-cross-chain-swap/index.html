Five Steps to Recover a Stuck Cross-Chain Swap

A stuck cross-chain swap needs a chain-by-chain check: verify the source transaction, trace the bridge, then use the route’s documented recovery path.

The Blocktape Editors Oct 16, 2026 · 08:26 UTC2 min read 7e5a13

A stuck cross-chain swap can be diagnosed in five steps: check the source transaction, trace the bridge transfer, verify the destination, then follow the route’s recovery instructions. Start with the transaction hash and the chain where you sent the funds; a wallet’s “pending” label does not show which part of the swap is delayed.

How do you check the source-chain transaction?

Open the sending chain’s block explorer and search the transaction hash to see whether the network accepted it. A pending transaction may be waiting for gas or network capacity; a failed transaction did not complete the on-chain action. If it is still pending, your wallet may offer a speed-up or cancellation, but these options apply only before confirmation and depend on the chain and wallet.

If the source transaction succeeded, record its status and check the swap route’s tracker or official status page. For background on how QuickSwap cuts swap steps, read the explanation there; the number of steps in a route does not tell you whether a transfer has settled.

How do you find where the swap stopped?

Check the route’s status against the source transaction hash, then compare it with the destination chain’s explorer. Cross-chain swaps involve separate transactions or messages: confirmation on the source chain does not by itself prove that the destination transfer has completed.

  • Source pending: Check the wallet’s transaction options and the chain’s current fee conditions.
  • Source failed: Review the explorer’s failure details before submitting the swap again.
  • Source confirmed, destination pending: Check the route tracker for a processing, relaying or settlement status.
  • Destination confirmed: Check the receiving address and token contract; the asset may not appear under the wallet’s default token list.

What should you do if the funds have not arrived?

Use the recovery path documented by the swap or bridge service for that transaction’s status. Some routes may allow a refund or a claim after a deadline; others require support to investigate. A successful source transaction cannot simply be cancelled, and a refund is not automatic across all routes.

Before taking action, match the transaction hash, wallet address, source and destination chains, and token amounts against the route’s official instructions. Do not share your recovery phrase or sign an unrelated transaction presented as a fix. If the route provides no self-service option, contact its official support with the hash and wait for its status update before retrying.
